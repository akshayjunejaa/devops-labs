# devops-labs
Hands-on labs for Linux, Git, Bash, Ansible, Docker, Kubernetes and infrastructure automation.

## Purpose
Hands-on practice to build, troubleshoot, and document infrastructure skills.

## Lab Topics
- Linux and Bash
- Git and version control
- Ansible automation
- Docker and Kubernetes
- Monitoring with Prometheus and Grafana
- Terraform and cloud fundamentals

Each lab will include commands, results, troubleshooting notes, and key learnings.
